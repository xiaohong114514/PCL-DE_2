> 版本：V0.1.0-dev ｜ 状态：开发中……

## 项目声明

**PCL-DE_2** 是基于 Plain Craft Launcher 2（PCL2）合理使用指南进行的**第三方独立二次创作项目**，与 PCL2 官方无任何隶属、代言或关联关系，并非官方续作。

本项目名称以 `PCL` 开头并附带第三方修改后缀 `DE_2`，符合《PCL 存储库合理使用指南》中对重度使用的命名要求。
